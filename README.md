# AND101 Project 3 - AnimalApps

Submitted by: Christian Hernandez

Time spent: 1 hours spent in total

## Summary

TwitchForTurtles is an android app that was riddle with some pretty nasty Kotlin bugs.  With those gone, it's a collection of widgets for a variety of purposes!  This app displays a mock-up of a login page for a potential video streaming site like Twitch that is marketed towards our shelled friends. They live for so long, why don't we find a way to make sure that they never get bored? 

If I had to describe this project in three (3) emojis, they would be: 🐢💻📽️
